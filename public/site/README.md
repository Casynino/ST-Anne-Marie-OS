# School images

Drop the school's own, approved images here. They appear on the public website automatically
(restart `npm run dev` or run `npm run site:media`).

| File | Where it shows |
|---|---|
| `logo.png` / `logo.svg` | Header and footer |
| `hero.jpg` | Home page, next to the headline (portrait works best, about 4:5) |
| `about.jpg` | About section (landscape, about 4:3) |
| `gallery/01-classroom.jpg` ... | Photo gallery (up to 8). The name after the number becomes the caption |

Only use photos the school has permission to publish. Photos of children need the parent or guardian's consent.
Keep each file under about 400 KB (resize/compress first) so pages stay fast on mobile data.
